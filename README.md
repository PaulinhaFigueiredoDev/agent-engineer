# Agent Engineer

Agent Engineer é quem projeta, constrói e avalia agentes de IA. Esse trabalho envolve definir a tarefa do agente, escolher o modelo, conectar ferramentas, estabelecer instruções e verificar se ele executa as ações corretamente.

Este repositório reúne meus conhecimentos, estudos e exemplos práticos sobre engenharia de agentes. O roadmap abaixo organiza os temas que pretendo abordar; os próximos temas ganharão links quando o conteúdo estiver disponível.
